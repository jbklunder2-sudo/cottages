HTML FILES - Files with extension .html - Each file is named corresponding to the names on your navigation bar. So for example your about.html contains information on "About" Page. Most changes will only happen in the html files. For eg, if you want to change the content on the page, or the pictures they will happen on the html pages. You can try to practice them here. 

index.html - Homepage
rates.html - Rates & Availability
gallery.html - Gallery
cottages.html - Cottages
contact.html - Contact
booking.html - Booking

The following pages pertain to each of the cottages which are listed under the Cottages tab on your navigation bar. 
cottage-1.html - Large One Bedroom Cottage
cottage-3.html - Two Bedroom Cottage
cottage-4.html - Small One Bedroom Cottage
cottage-7.html - Four Bedroom Cottage
cottage-10.html - Studio Cottage

JAVASCRIPT FILES - Files with the extension .js - Mostly will remain untouched with some exceptions below. These files are in the folder named js

banner.js - Not to touch. this is for your banner placeholder only. 
banner.json - Not to touch. this is for your banner text and image only. You can choose to change them when you feel that way. 
bookings.json - This is the file you will manually update to block dates on your calendar when someone sends you a booking request.
calendar.js - Not to touch. This is what has set the calendar for you.
cottages.js - This is the file when you want to change the prices for your cottages. The only change you should do is where it says rate: "$220/night" or the name: ""
gallery.js - Not to touch except when you want to include some images at the very top.
ical.js - Not to touch. This file is used in your rates.html, and all your cottage-n.html 
menu.js - Not to touch. This is for the hamburger menu on the mobile view. 

CSS FILE

style.css - At the moment don't change anything. But in the future if you want to change the aesthetics of the website, this is your file. This file is in the folder named css.

There is a folder called images which contains all the images which we are using in the website except for the ones on the gallery page. Within this folder there are sub-folders named cottage1, cottage2 etc just to separate the images so that it does not cause confusion.
